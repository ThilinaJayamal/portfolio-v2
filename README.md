# Portfolio V2 - Thilina Jayamal

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white) ![JavaScript ESM](https://img.shields.io/badge/JavaScript-ESM-F7DF1E?logo=javascript&logoColor=black) ![Vite](https://img.shields.io/badge/Vite-7-646CFF?logo=vite&logoColor=white) ![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4-38B2AC?logo=tailwindcss&logoColor=white) ![Lucide React](https://img.shields.io/badge/Lucide-React-000000?logo=lucide&logoColor=white) ![React Icons](https://img.shields.io/badge/React-Icons-blue?logo=react&logoColor=white)

A modern, responsive, and highly interactive personal portfolio website built with **React 19**, **Vite**, and **Tailwind CSS 4**. This project showcases software engineering expertise, educational background, and a diverse range of full-stack and mobile projects.

## 🚀 Live Demo

[View Live Portfolio](https://thilinajayamal.me)

## ✨ Key Features

* **Modern Tech Stack:** Built using the latest React 19 features and Tailwind CSS 4 for high-performance styling.
* **Interactive UI:**
* **Particles Background:** Dynamic particle effects in the Hero section.
* **Smooth Scrolling:** Integrated `react-scroll` for seamless navigation between sections.
* **Animations:** Powered by `framer-motion` for smooth transitions and scroll-based effects.
* **Logo Loop:** An infinite marquee showcasing technical skills and tools.


* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views with a dedicated mobile navigation menu.
* **Dynamic Sections:**
* **Hero:** Animated typing effect highlighting roles.
* **About Me:** Quick stats and professional summary.
* **Projects:** Filterable project showcase with links to GitHub and live demos.
* **Education:** Timeline-style view of academic qualifications and certifications.



## 🛠️ Tech Stack

### Frontend

* **Core:** React 19, JavaScript (ESM).
* **Build Tool:** Vite 7.
* **Styling:** Tailwind CSS 4, Lucide React (Icons), React Icons.
* **Animation:** Framer Motion, ReactBits, Lenis (Smooth Scroll).

### Deployment & Tools

* **Deployment:** GitHub Pages (via `gh-pages` package).
* **Linting:** ESLint.
* **Icons:** React Icons, Lucide React.

## 💻 Getting Started

### Prerequisites

* Node.js (Latest LTS recommended)

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/ThilinaJayamal/portfolio-v2.git
cd portfolio-v2

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run in development mode:**
```bash
npm run dev

```


4. **Build for production:**
```bash
npm run build

```



### Deployment

The project is configured to deploy to GitHub Pages:

```bash
npm run deploy

```
